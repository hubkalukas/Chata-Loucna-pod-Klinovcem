## O ubytování

- **Poloha:** 350 m od sjezdovky a 500 m od lanovky Dámská (Skiareál Klínovec).
- **Kapacita:** Celá chata jen pro vás — **2 ložnice** a obývací pokoj pro **1–7 osob**.
- **Vybavení:** Krbová kamna, podlahové topení a kompletní zázemí pro zimní i letní pobyt.
- **Rezervace:** Přímé propojení na ověření volných termínů na *e-chalupy.cz*.

## Technické provedení

- Jednostránková responzivní prezentace (`index.html`) bez externích build nástrojů.
- Hostováno zdarma přes **GitHub Pages**.
